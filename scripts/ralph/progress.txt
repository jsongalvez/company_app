## Codebase Patterns
- Backend module: Kotlin (JVM) + Javalin + Exposed (DSL) + Flyway, package root `com.companyb.companyapp`. Layers: `api/routes`, `service`, `repository` (+ `repository/model` for Exposed `Table` objects), `auth`, `database`, `logging`.
- Quality gate (run per backend change): `./gradlew :backend:detekt :backend:ktlintCheck :backend:test`. ktlint auto-fix: `./gradlew :backend:ktlintFormat`.
- detekt `MagicNumber` is strict: extract any literal (column widths, pool sizes, durations) to a `private const val`. Constants are exempt via `ignoreConstantDeclaration`. `ReturnCount` max is 2 — match the existing pattern of `@Suppress("ReturnCount")` used in AuthService.
- detekt requires the `detekt-formatting` plugin (wired in root `build.gradle.kts` `subprojects { dependencies { add("detektPlugins", ...) } }`) because `detekt.yml` enables the `formatting` ruleset.
- Authorization MUST go through `CapabilityService.hasCapability(userId, capabilityCode, contextType, contextId)` which queries the `active_user_capabilities` SQL view. Never check roles directly in business logic. The view already filters INACTIVE users and time windows.
- For Postgres enum columns in raw SQL, bind params as text and cast in SQL (e.g. `?::capability_context_type`, `?::uuid`) via Exposed `transaction { exec(sql, args = listOf(TextColumnType() to value)) { rs -> ... } }`. Avoids Exposed PG-enum operator mismatches. This also applies to writes: Exposed `enumerationByName` binds varchar, so native enum updates need raw SQL casts like `SET status = ?::user_status`.
- Immediate revocation: `DenyList` (in-memory `ConcurrentHashMap<UUID, Instant>`) is checked inside `JwtService.verifyToken` BEFORE the DB `authorize` call. Populated at startup via `DenyList.loadInactiveUsers()` in `Main.kt`. Entries auto-evict after 24h (JWT max expiry).
- No Postgres/Docker available in this environment — DB integration tests cannot be run here. Write DB-free unit tests (inject time via internal `*At(now)` helpers as done in `DenyListTest`).
- Exposed needs `exposed-java-time` dependency for `timestampWithTimeZone`/`CurrentTimestampWithTimeZone`.
- HTTP errors are signalled by throwing Javalin's built-in response exceptions from the service layer (`ForbiddenResponse`=403, `BadRequestResponse`=400, `NotFoundResponse`=404, `UnauthorizedResponse`=401). No custom exception hierarchy.
- Day state is lazy: reuse `BranchDayService.evaluateStatus(status, date, today)` — an OPEN day with date < today(Asia/Manila) is treated as PAST without a DB write. Call `BranchDayService.assertEditable(branchDayId, userId, reason?)` before any operational/financial write.
- For testable time logic, keep pure functions taking explicit `today`/inputs and have the public method fetch `LocalDate.now(zone)` then delegate (see BranchDayServiceTest, DenyListTest).
- Protected (authenticated) routes MUST be registered under `/api/*` — only that path is guarded by the `before("/api/*")` filter which sets `context.attribute("userId", <jwt-subject String>)`. Public routes (auth) have no prefix. Read caller id with `UUID.fromString(context.attribute<String>("userId"))`. Register each route object in `Main.initializeJavalin`.
- Audit logging: call `AuditLogRepository.record(tableName, recordId, action, changedBy, oldValue?, newValue?, reason?)` from inside the repository's `transaction {}` — it nests/joins the outer transaction so the audit row commits atomically with the change. Build JSON values with `AuditLogRepository.jsonField(key, value)`. `old_value`/`new_value` are JSONB bound as text with `?::jsonb`.
- GLOBAL-scoped capability checks use `CapabilityService.GLOBAL_CONTEXT_ID` (nil all-zero UUID) as the contextId with `CapabilityContextType.GLOBAL`.
- Kotlin file naming: detekt `MatchingDeclarationName` requires the file name to match its single top-level declaration (e.g. enum `AuditAction` must live in `AuditAction.kt`, not `AuditLog.kt`).
