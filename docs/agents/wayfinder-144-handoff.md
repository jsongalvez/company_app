## Patterns + learnings (cumulative across sessions)

- **Session-42 additions**:
  - **The convergence curve was 3 iterations on one race class**: cold↔refresh needed pass-5 (failure side) + pass-6 (success side) + the pass-8 log-wording polish. The invariant reasoning ("cold only launches from Loading/Error/Idle") was the convergence key — same shape as #143's reload race.
  - **Generation guards over cancellation**: for applyFilters-vs-in-flight, the stale response is made inert by a generation check rather than cancelling the job — cancellation would have made the guard deterministically untestable (cancel-at-resume kills the in-flight transform before it can be observed). The gate-tests pin the actual mechanism.
  - **Test-harness gates**: per-call `CompletableDeferred` gates in the MockEngine handler (body index assigned on ENTRY, before the gate await — a suspended request holds its slot) make any landing-order deterministic. This is the tool for race pins.
  - **Saveable flags lie across process death**: a fresh VM + restored saveable flags bypass load-on-entry. The fix: derive load decisions from VM list state (Success → silent, Idle/Error → cold); keep saveable state only for what VM state can't express (tab, visited, draft).
  - **Layout bugs are a real HARD class**: the D5 Load-more button was clipped for the surface's entire life (two build-time review rounds + 6 loop passes missed it — it took a behavior-trace phase tracing the D5 flow end-to-end to catch). The modifier chain (weighted Column → fillMaxSize child → zero-height siblings) is now a known trap.
  - **detekt on composeApp actuals**: the ungated composeApp detekt still flags standards breaches (LongParameterList); actuals are the natural suspects. The holder extraction that fixed it also dissolved a 6×-accepted Data Clump — sometimes the HARD fix is the SOFT fix.
  - **Sub-agent flakiness**: P2/P4 phases returned empty responses repeatedly; the loop must not silently drop a phase — re-run or run inline with the identical lens.
