7. **Q7 — Responsive integration (no new decision; verification with one implementation seam).** Cross-platform state (`NotificationState`, `SessionState`, `DrawerViewModel`, `NotificationBadgeViewModel`'s polled count) all commonMain — no per-platform state stores.
