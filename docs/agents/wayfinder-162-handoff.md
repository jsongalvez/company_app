## Patterns + learnings (cumulative)

- **Session-59 additions**:
  - **A keyed mirror closes cross-key races by construction, but NOT same-key ordering**: two loads of one key in flight → the older snapshot can be the last writer. Fix shape: newest-launch-wins stamp gating the commit (chosen — unguarded loads that must never skip), or a per-key in-flight guard (chosen in #161 for Remittance — where a skipped refetch is safe). Register row `keyed-mirror ordering`.
  - **Main.immediate changes what "dispatch boundary" means**: the launch body runs INLINE up to the first suspension — Loading is set in the caller's frame, and a StateFlow collector on Main.immediate resumes inline at every value assignment. Claims about "by the time X, the collector has converged" must cite INLINE CONVERGENCE, never a boundary. This session's own KDoc got this wrong once (pass-3 HARD, truth-class) and the unqualified "one collector hop lag" claim survived in 3 more KDocs (pass-4 HARD) — when fixing a doc-truth, grep the claim across the whole file set.
  - **`freshestValue()` discipline**: VM-internal mutation transforms must read state-first (`Success?.data`) — never a collected flow's `.value` (can lag under test dispatchers; the register's stale-snapshot class) — with the mirror as the Loading/Error fallback (mutations gated during Loading anyway).
  - **The unifier's READ side ≠ its WRITE side**: KeepLast unified the freshest read; the in-place mutation write (`freshestValue() ?: return → filterNot → Success(...)`) remains hand-rolled at 4+ sites — the P5 graduate `KeepLast.mutate(transform)`.
  - **A throwaway state flow is an adapter over the handler's mandatory `state` param**: two sites now (sentListFlow, UserVM mutation flow) — the state-less `launch` variant graduate would kill both.
- Prior-session patterns unchanged: claim first, facts-via-code, one-ticket-per-session, resolution → close → map update → handoff, batch-fix commits per pass, `git diff <last-pass-commit>` per pass. **No fix-that-didn't-land this session** (every batch grep-verified).
