## Patterns + learnings (cumulative across sessions)

- **Session-46 additions**:
  - **The count-0 misfire class recurred with a NEW shape**: not a swallowed-write fallback but a version-lock race — the service's version pre-check runs in its own committed transaction, and the repo's conditional UPDATE discarded the affected-row count, so a concurrent commit between the two served the OTHER writer's row as the caller's own 200 (a silent lost update, ADR-0022's core prohibition). The fix is the register class's canonical shape: check the affected count, throw (here `VersionMismatchException`, ADR-0016). Register bumped to 3.
  - **A guard that blocks a path must keep the path's UI visible**: the conflict commit-block (correct on its own) made `withDraft`'s unconditional error-clear hide the error + Reload button — the machine parked silently with no visible exit. When a fix removes an action, it must re-check the states that keyed off that action's feedback.
  - **Version-monotonic merges close the stale-poll-after-commit class**: an in-flight poll response that started before a committed edit carries an older version; merging per-row by version (incoming wins only when ≥) means the commit and the poll can never disagree on screen — cheaper than a refetch-on-commit.
  - **The baseline-version snapshot at edit start is the pessimistic model's lost-update guard**: capturing the version at commit-time-from-the-live-row would silently adopt a mid-edit remote change and overwrite it (a lost update); snapshotting at edit start makes the mid-edit remote change surface as the locked 409 → reload → changed-indication path.
  - **A parked invisible state is a wedge**: the error-guard (blocked cell-switch) is only correct while its row exists; membership-authoritative merges can make the row vanish (day rollover), so the guard must fail-closed the machine when its row is gone, or every future edit dies until VM re-entry.
- Prior-session patterns unchanged: AFK flow = quality gate, phased loop per `docs/agents/code-review-loop.md`, resolution comment → close → map Decisions-so-far + frontier paragraph + handoff. **k6 was deferred with a logged reason for the first time on a consumer-backed endpoint** — the grant channel is the blocker (DevSeeder GLOBAL grants can't pass the strict BRANCH gate; no HTTP self-grant endpoint exists); the #140 precedent stands, the land-condition is documented in the resolution + map.
